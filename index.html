一、它怎么工作

问题进来后先做中文分词（单字 + 二元词），用 BM25 在 26 段校史原文里排序，取最相关的 3 段；再从段落中挑出最能回答问题的句子，组成回答并挂上出处编号。整个过程在浏览器本地完成，不联网、不上传、不调用任何外部接口——断网也能用。

二、为什么不会胡编

本地模式的答案全部是原文句子的摘录与重组，不生成任何新事实。检索不到，它会直接说"知识库中没有收录"，并给出最接近的三条，而不是编一个看起来合理的答案。

三、AI 增强模式

可选：填入你自己的大模型 API Key（OpenAI 兼容接口，如 DeepSeek），应用会把检索到的原文作为上下文交给模型，要求它只依据资料作答并保留 [S1] 式引用。Key 只存在你本机浏览器里，不会发往除模型服务商以外的任何地方。
